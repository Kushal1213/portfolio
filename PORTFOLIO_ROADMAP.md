# Portfolio recruiter roadmap

## Goal

Help a recruiter understand role fit, technical depth, evidence, and the next action within one minute while preserving enough detail for an engineering reviewer.

## Completed

- Lead with current product work instead of a chronological project dump.
- Show Cuepoint, Veyra, KaamKaaj, GPT From Scratch, and grounded RAG first.
- Preserve five detailed case studies and the complete 43-repository archive.
- Add measurable proof from AMD open source, fraud detection, voice AI, analytics, and healthcare ML.
- Add a recruiter snapshot with target roles, graduation, scale, contribution proof, résumé, and direct email.
- Replace the stale résumé download with the latest one-page PDF.
- Align title, metadata, structured data, navigation, typography, motion, and reduced-motion behavior.

## Next highest-impact work

1. Add real product screenshots for Cuepoint, Veyra, and KaamKaaj so each priority project has immediate visual proof.
2. Repair and verify the public deployment and connect a stable custom domain.
3. Check every repository and live-demo link monthly; remove or clearly label unavailable demos.
4. Add privacy-respecting analytics for résumé downloads, project opens, email clicks, and section completion.
5. Add short architecture diagrams to Cuepoint, Veyra, and the fraud system using the same visual language.

## Later improvements

- Add verified recommendations only when real collaborators or maintainers provide them.
- Publish concise engineering notes about one difficult tradeoff per major project.
- Add a lightweight GitHub synchronization job for repository count and recent work.
- Create role-specific résumé variants only when applying to materially different job families.

## Success measures

- Recruiters reach a priority project or résumé within 30 seconds.
- At least one project or résumé interaction per qualified visit.
- No broken production links.
- Mobile Lighthouse performance and accessibility remain above 90.
- Portfolio copy and résumé remain factually synchronized.
